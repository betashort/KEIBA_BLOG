# 素材

* サムネイルに載せるモチーフを置く。
* 透過 PNG を推奨する。  
* 単色の幾何・シルエット・イラスト。
* 数字・馬名・クラブロゴ・実写の顔は焼かない。
* 生成プロンプトは各素材の md にある。
