## 2. 2系統の資産

同じファイルを使い回さない。役割が違う。

| 系統 | 何を表すか | 使う場所 | 仕様 |
| ---- | ---------- | -------- | ---- |
| **作者アイコン** | 人（βshort） | X、プロフィール写真 | [author-icon.md](./author-icon.md) |
| **サイトエンブレム** | 場（競馬βLab） | favicon、Header、タッチアイコン | [emblem.md](./emblem.md) |

現状は `favicon.ico` が作者アイコンのままブラウザタブにも出ている。タブ 16px ではキャラクターが潰れるので、公開用 favicon はエンブレムに差し替える。作者アイコンは SNS・プロフィール側に残す。

用途と書き出しサイズは [usage.md](./usage.md)。

## 3. 方針（要約）

1. **作者とサイトを分ける。** キャラクター絵は個人の顔。サイトの印は中央の蹄鉄と、左右の β（翼）。
2. **16px でシルエットが残ること。** エンブレムは幾何・単色。目・髪・煙は焼かない。
3. **既存ルールに合わせる。** サイト名は「競馬βLab」。クラブロゴ・JRA・実在馬は使わない。牡／牝の性別色はエンブレムの塗りにしない。
4. **ラフはプロンプトで作る。** 正方形・単色。ICO に写真を入れない。

詳細は各仕様。生成プロンプトは [prompts.md](./prompts.md)。完成稿は未作成。
