# 作者アイコン

上位文書: [索引](./README.md)  
対象ファイル（現状）: `keiba-blog/public/favicon.ico`

βshort 個人の顔。サイトの印ではない。

## 1. 現状

X などの SNS アイコンとして、サイトの `favicon.ico` を流用している。

| 項目 | 値 |
| ---- | -- |
| ファイル | `keiba-blog/public/favicon.ico` |
| 容量 | 約 428 KB |
| 内包サイズ | 64×64、128×128（DIB）、256×256（PNG） |
| 背景 | 白（`#ffffff`） |
| 画風 | アニメ調の胸から上の人物画 |

参照書き出し（ICO から抽出）:

- 256px: [assets/author-icon-current.png](./assets/author-icon-current.png)
- 64px: [assets/author-icon-64.png](./assets/author-icon-64.png)（タブサイズに近い縮小）

## 2. 見た目の要素（現行）

仕様として固定する要素。差し替えるときはこの表を更新する。

| 要素 | 指定 |
| ---- | ---- |
| 被写体 | 一人の女性キャラクター。胸から上、正面 |
| 髪 | 黒髪・長髪・前髪あり |
| 目 | 赤（サイトの識別アクセントの参照元） |
| 服 | 暗い無地（黒〜チャコール） |
| 背景 | 白。グラデーションや風景は置かない |
| 構図 | 中央。余白は均等 |

サイトエンブレムへは、**黒・白・赤の対比**だけを持ち込む。人物・小物は持ち込まない（[emblem.md §7](./emblem.md)）。

## 3. 使う場所

| 場所 | 扱い |
| ---- | ---- |
| X（旧 Twitter）プロフィール | 正とする。円クロップは SNS 側 |
| その他 SNS の顔写真 | 同じ画像を使う |
| サイト `/profile` | `/images/author/icon.png` を円表示 |
| ブラウザ favicon | **使わない**（エンブレムへ移行） |
| Header ロゴ | **使わない** |

## 4. 保管（移行後）

`favicon.ico` をエンブレムに差し替えたあと、作者アイコンは別パスに置く。

| 種類 | パス |
| ---- | ---- |
| 参照（本仕様） | `doc/design-emblem/assets/author-icon-current.png` |
| 本番 | `keiba-blog/public/images/author/icon.png`（URL `/images/author/icon.png`） |

推奨マスターは **400×400 PNG**（X の推奨に合わせる）。現行 256 を引き伸ばさない。必要なら 256 を正とし、それ以上は作らない。

形式: PNG、sRGB、白背景を焼き込む（透過にすると円クロップで黒縁が出やすい）。

## 5. 禁止

- 作者アイコンをサイトエンブレムのマスターにしない
- 16px / 32px 用にキャラクターをトレースして favicon を作らない
- クラブロゴや馬の写真を作者アイコンに合成しない
