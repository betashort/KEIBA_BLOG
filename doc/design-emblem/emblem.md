# サイトエンブレム

上位文書: [索引](./README.md) / [用途とサイズ](./usage.md)  
生成: [prompts.md](./prompts.md)

競馬βLab の印。作者アイコン（キャラクター）とは別物である。

## 1. 印象

蹄鉄に β の羽が生えた印。中央は馬、左右は作者名。キャラクター絵より先に、タブとヘッダーでサイト名と結びつくこと。

| 読み取り | 根拠 |
| -------- | ---- |
| 蹄鉄（中央） | 競馬。サムネ素材と同じ開口下の U 字（[design-image-catalog/assets](../design-image-catalog/assets/README.md)） |
| 左右の β | 作者名 βshort。サイト名の核。蹄鉄から生えた翼 |
| 黒・白・赤 | 作者アイコンから借りる対比。人物は借りない |

鳥の羽・ペガサス・天使は描かない。翼に見えるのは **β の字形そのもの** である。

## 2. 形（マスター）

正方形キャンバス。円にクロップしても欠けない。

横並びに3つ置く。核は中央の蹄鉄。β は蹄鉄の内側ではなく、**左右外側**。

| レイヤ | 位置 | 内容 |
| ------ | ---- | ---- |
| 核 | 中央 | 蹄鉄。U 字、**開いた側が下**。太さはキャンバス幅の 8–10%。端は丸める |
| 左翼 | 蹄鉄の左 | **β を左右反転**したモチーフ。ステムが蹄鉄側、ボウルが外側 |
| 右翼 | 蹄鉄の右 | **β をそのまま**。ステムが蹄鉄側、ボウルが外側 |
| 接合 | 左右 | β のステムが蹄鉄の外縁に接する（またはわずかに重ねる）。浮かせて離さない |
| アクセント（任意） | 両 β のカウンター | 閉じた穴をブランド赤で点す。左右対称。16–32px では省略 |

左右反転は **水平ミラーのみ**（`scale(-1, 1)`）。上下反転・90°回転はしない。β として読めなくなる。

翼らしく見せるために、左右の β を外向きに 8–12° 開いてよい。開く場合も左右対称。16px 用は回転なし。

コンストラクションの寸法:

| 項目 | キャンバスに対する比 |
| ---- | -------------------- |
| セーフエリア | 中央 80%（外周 10% はクリアスペース） |
| 全体の外接幅 | セーフエリアいっぱい（翼が横に張る） |
| 蹄鉄の幅 | 全体幅の 32–36% |
| 蹄鉄の高さ | 全体高さの 52–58% |
| β の高さ | 蹄鉄の高さの 70–80% |
| 光学中心 | 蹄鉄の幾何中心。キャンバス中心より **2% 上**（U 字が下に開くため） |

ラフは [prompts.md](./prompts.md) で生成する。左右の β は **同一字形をミラー** して作る（太さやカウンターが左右で違わないこと）。完成稿は単色のパスにトレースしてよい。

## 3. 縮小ラダー

一つのマスターから落とす。サイズごとに「蹄鉄の中に β」など別コンセプトにしない。

| 表示 | 残すもの | 落とすもの |
| ---- | -------- | ---------- |
| 256–64px | 蹄鉄 + 左右の β + 赤点（任意） | — |
| 32px | 蹄鉄 + 左右の β | 赤点、β の回転、蹄鉄の内側ハイライト |
| 16px | 蹄鉄＋翼の外輪郭（カウンターは潰してよい） | 赤点、β としての可読 |

16px で左右の β が文字として読めなくてよい。**翼の付いた蹄鉄** としてシルエットが残ればよい。それでも潰れるときは蹄鉄のみ。Header の横に「競馬βLab」がある前提。

## 4. カラー

本文 UI は白地（Header `bg-white`、文字 `text-gray-900`）。サムネは暗いキャンバス（[common.md](../design-image-catalog/common.md)）。エンブレムは両方に置けるよう、単色＋反転を正とする。

| トークン | 値 | 使い方 |
| -------- | -- | ------ |
| `--brand-ink` | `#171717` | 白地のマーク・蹄鉄・β（`gray-900` に合わせる） |
| `--brand-paper` | `#ffffff` | 白地、favicon 既定の背景 |
| `--brand-inverse` | `#f4f1ea` | 暗地のマーク（サムネの `--thumb-fg` と同じ） |
| `--brand-accent` | `#9f1239` | 左右 β のカウンター。作者アイコンの赤目の参照。牝馬色 `#dc2626` とはずらす |

バリエーション:

| 名前 | マーク | 背景 | 使う画面 |
| ---- | ------ | ---- | -------- |
| ライト | ink | paper | Header、本文、白 favicon |
| ダーク | inverse | なし（透過）またはインクに近い暗色 | 暗地サムネ、将来の暗色 UI |
| バッジ | inverse のマーク、ink の円塗り | 円を塗りつぶす | apple-touch、PWA。翼が円からはみ出さないよう少し縮小 |
| アクセント | ライトと同じ + 左右カウンター赤 | paper | プロフィールやフッター。16px では使わない |

性別色（`--sex-male` / `--sex-female`）で塗らない。一口馬主の牡／牝と衝突する。カテゴリ色（ブログ金・研究青・予想金など）もエンブレムには使わない。カテゴリ識別はサムネ側の仕事である。

左右の β を違う色にしない（片翼だけ赤、など）。対称を崩す。

## 5. ワードマーク（Header）

Header は現状サイト名テキストのみ（[UI設計 共通](../03_design/UI_design/common.md)）。エンブレムを足すときは横並びのロックアップにする。

| 項目 | 指定 |
| ---- | ---- |
| 並び | 左: エンブレム、右: `競馬βLab` |
| エンブレム高さ | 文字のキャップハイトに合わせる（おおよそ 28–32px） |
| キャンバス | 正方形のまま（翼は横に張るので、高さ基準でスケールする） |
| 間隔 | エンブレム幅の 0.2（翼がある分、少し詰めてよい） |
| フォント | 本文 UI に合わせる。明朝は使わない |
| リンク | ロックアップ全体が `/` |
| 改行 | しない。「競馬」「βLab」を縦に積まない |

ロックアップは生成しない。マークだけ作り、サイト名は Header 側で乗せる。

## 6. タイポグラフィ（β）

| 項目 | 指定 |
| ---- | ---- |
| 文字 | U+03B2 GREEK SMALL LETTER BETA（`β`）。ラテン `B` や ss 字形で代用しない |
| 左右 | 右は原形。左は同じ字形の左右反転。別のフォント・別ウェイトにしない |
| ウェイト | 700–800。32px でカウンターが埋まらない太さ |
| デザイン | サンセリフ。フック（尻尾）は下外へ流してよいが、蹄鉄の開口（下）と交差させない |
| サイト名 | 既存どおり「競馬βLab」。エンブレム内に「Lab」「競馬」は書かない |

## 7. 禁止

- 作者アイコンの人物・髪・目のハイライト・小物をトレースする
- クラブロゴ、JRA ロゴ、勝負服の複製
- 実在馬の顔、写真の切り抜き
- **β の代わりに鳥の羽・翼・ペガサスを描く**
- β を蹄鉄の**内側**に置く（本仕様の核は中央蹄鉄＋左右翼）
- 左右とも同じ向きの β にする（左は反転が必須）
- 予想印 ◎ をエンブレムの核にする（`predict` カテゴリの領域）
- コース楕円をエンブレムの核にする（`analysis` の領域）
- 馬券チケット形（`baken` の領域）
- グラデーション・ドロップシャドウ・光彩（16px で汚れる）
- エンブレム内にサイト名や URL を入れる
- 牝馬赤 `#dc2626` や牡馬青 `#2563eb` でフレームを塗る

## 8. マスターと完成稿

| 項目 | 指定 |
| ---- | ---- |
| マスター生成 | 1024×1024 PNG（[prompts.md](./prompts.md)） |
| 置き場（ラフ） | `doc/design-emblem/assets/` |
| 置き場（本番） | [usage.md](./usage.md) |
| 色空間 | sRGB |
| 完成判定 | 32px で「蹄鉄に左右の翼」と読める。左右の β がミラー対。白地・暗地の両方でコントラストが足りる。円クロップではみ出さない |

拡散モデルは β の左右反転が弱い。崩れたら [prompts.md §7](./prompts.md) の分割生成に切り替える。完成稿はパスにトレースしてよい。
