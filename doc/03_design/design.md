## 1. はじめに

### 1.1 目的

本書は、競馬ブログシステムのソフトウェア設計内容を明確にし、  
開発・テスト・保守を円滑に進めることを目的とする。

### 1.2 対象読者

- 開発者
- テスター
- プロジェクト管理者
- 保守担当者

### 1.3 用語・略語

| 用語         | 説明                                   |
| ------------ | -------------------------------------- |
| Markdown     | 記事作成に使用する軽量マークアップ言語 |
| OGP          | SNS共有時に表示されるメタ情報          |
| Twitter Card | X（旧Twitter）向けOGP拡張              |

<div style="page-break-after: always;"></div>

## 2. システム概要

### 2.1 システム構成図

（静的サイト構成：React + Vite + Xserver）

### 2.2 処理概要

- Markdownで作成した記事をビルド時にHTMLへ変換
- 変換したHTMLを記事ページ・一覧ページに表示
- 静的ファイルとしてXserverへデプロイ

<div style="page-break-after: always;"></div>

## 3. 設計方針

### 3.1 設計方針

- スマートフォン閲覧を前提としたモバイルファースト設計
- 静的ビルドによる高速表示
- 記事追加・修正が容易な構成
- SEO・OGPを重視した設計

### 3.2 命名規則

- コンポーネント名：PascalCase
- ファイル名：camelCase
- URLスラッグ：kebab-case

### 3.3 コーディング規約

- 使用言語：TypeScript
- フレームワーク：React
- ビルドツール：Vite
- UI：Tailwind CSS

<div style="page-break-after: always;"></div>

## 5. 機能設計（処理設計）

### 5.1. 機能一覧

| 機能ID | 機能名             | 概要               | 要件ID |
| ------ | ------------------ | ------------------ | ------ |
| F-001  | 記事表示           | Markdown記事の表示 | R-001  |
| F-002  | 記事一覧表示       | 新着順一覧表示     | R-002  |
| F-003  | カテゴリ・タグ管理 | 記事分類           | R-003  |
| F-004  | OGP表示            | SNS共有対応        | R-004  |
| F-005  | 広告表示           | Google Ads表示     | R-005  |

### 5.2 機能詳細

#### 5.2.1. 機能ID：F-001 記事表示

- 概要：MarkdownをHTMLへ変換し表示
- 入力：Markdownファイル
- 出力：HTMLページ
- 処理内容：
  - gray-matterでFrontMatter解析
  - markedでMarkdownをHTML変換
  - dangerouslySetInnerHTMLで描画
- 例外処理：未定義

## 6. データベース設計

※本システムはDBを使用しない

### 6.1 データ管理方針

- 記事データはMarkdownファイルで管理
- 画像は記事フォルダ配下に配置

### 6.2 フォルダ構成

```txt
src/articles/
├─ blog/
│  ├─ article1/
│  │  ├─ index.md
│  │  └─ hero.png
├─ study/
│  ├─ article1/
│  │  ├─ index.md
│  │  └─ hero.png
```

## 8. 非機能設計

### 8.1 性能要件

* LCP 2.5秒以内を目標
* 静的ビルドによる高速表示

### 8.2 セキュリティ

* ユーザー入力機能なし
* Markdownは管理者作成のみ
* 外部スクリプトは信頼済みのみ使用

### 8.3 SEO・OGP

* title / meta description 設定
* h1は1ページ1つ
* パンくずリスト設置
* OGP・Twitter Card対応
* sitemap.xml / robots.txt生成
