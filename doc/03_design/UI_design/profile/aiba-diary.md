## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/profile/hitokuchi-portfolio/{bamei}` |
| 説明 | 出資馬ごとの日記・観戦記・思い出を記録・表示する |
| 対応コンポーネント | `AibaDiary` |
| og:type | `article` |

## 2. レイアウト

* パンくず（ホーム > プロフィール > 一口馬主ポートフォリオ > 馬名）
* 対象馬の見出し（馬名）と関連馬情報（所属クラブ・戦績などへのリンク／簡易表示）を上部に表示
* タブで切り替え表示する
  * 紹介
  * 日記
  * 血統
  * 分析
* 紹介タブ
  * 写真（`index.md` Front Matter の `photos`。先頭に表示。複数枚はスライドショー。`src` は `/images/hitokuchi/{馬名}/...`）
  * 紹介表（誕生日・毛色・生産牧場・育成牧場・募集価格。`index.md` Front Matter）
  * レース成績表（日記 Front Matter の `race` から集計。レース名クリックで日記タブへ）
* 日記タブ
  * 目次（各日記の日付・見出し。クリックで該当観戦記へ）
  * 日記・観戦記（`{YYYY-MM-DD}-{slug}.md` を埋め込み。個別 URL にはしない）
  * 各日記の写真（日記 Front Matter の `photos`。見出しの直後。複数枚はスライドショー）
* 血統タブ
  * 5代血統表（`index.md` Front Matter の `pedigree`。父系は青・母系は赤）
* 分析タブ
  * 出走成績からの簡易集計（出走・勝利・獲得賞金・一口の回収率、勝率／連対率／複勝率／掲示板率、着順・開催場・コース）
  * 一口の回収率は獲得賞金 / 募集価格。募集価格未設定時は「—」
* 一口馬主ポートフォリオ一覧からのリンクで遷移する
