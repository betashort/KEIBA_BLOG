## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/profile` |
| 説明 | 運営者の自己紹介を表示 |
| 対応コンポーネント | `Profile` / `MetaTags` |
| og:type | `website`（または `profile`。実装方針未決） |

## 2. レイアウト構成

```
Header
└─ Main
   ├─ ページ見出し（プロフィール）
   ├─ プロフィール本文
   └─ サイト概要
Footer
```

## 3. UI要素一覧

| 要素 | 必須 | 説明 |
| ---- | ---- | ---- |
| ページ見出し | ○ | 「プロフィール」等 |
| プロフィール本文 | ○ | 運営者の自己紹介 |
| サイト概要 | ○ | サイトの目的・扱うコンテンツの説明 |
| アイコン / 写真 | △ | 要否・配置は未決 |
| SNS リンク | △ | 要否は未決 |

## 4. インタラクション

- SideNav / ホームからの導線で到達
- パンくずを置く場合：ホーム > プロフィール（任意）

## 5. 表示状態

| 状態 | 表示 |
| ---- | ---- |
| 通常 | 本文・サイト概要を表示 |
| （静的ページのため空状態は基本なし） | — |

## 6. レスポンシブ

| 方針 | 内容 |
| ---- | ---- |
| 本文幅 | 記事詳細と同様の可読幅を検討 |
| モバイル | 縦積み。画像がある場合は上または横並び崩れ防止 |
