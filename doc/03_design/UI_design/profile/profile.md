## 2. レイアウト

* ページ見出し「プロフィール」を表示
* 作者アイコン（円）と表示名を並べて表示
  * 画像は `/images/author/icon.png`（[作者アイコン](../../../design-emblem/author-icon.md)）
  * 肩書き「運営者 / ソフトウェアエンジニア」
* SNSリンクを表示（新規タブ）
  * X（`https://x.com/i_thinking_reed`）
  * GitHub（`https://github.com/betashort`）
* プロフィール本文を表示
* 競馬のスタンスを表示（「再現性のある予想を!」）
* 好きな競馬場・レース・券種を表示
  * 競馬場：東京競馬場
  * レース：ジャパンカップ
  * 券種：ワイド / 三連複 / 3連単 / WIN5
* サイト概要を表示
* 関連ページへの導線を表示
  * 一口馬主ポートフォリオ（`/profile/hitokuchi-portfolio`）
  * 馬券ポートフォリオ（`/profile/baken-portfolio`）
* 免責を表示（予想・買い目は自己責任）
