## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/profile/baken-portfolio/{YYYY-MM}` |
| 説明 | 月次の馬券成績記事。サマリ・券種・購入履歴と振り返り本文を表示する |
| 対応コンポーネント | `BakenMonthlyPost` |
| og:type | `article` |

## 2. レイアウト

* パンくず（ホーム > プロフィール > 馬券ポートフォリオ > YYYY年M月）
* ページ見出し（Front Matter の title）を表示
* 当月サマリを表示
  * 収支・的中率・回収率
* 本文（Markdown）を表示
* 券種別の集計を表示（Front Matter にあれば）
* 購入履歴を表示（Front Matter にあれば）
* 馬券ポートフォリオの年月リンクから遷移する

データは `src/articles/baken/{YYYY-MM}/index.md`。`template` フォルダは読み込み対象外。

**ワイヤーフレーム**
```
+--------------------------------------------------------+
|                        Header                          |
+--------------------------------------------------------+
|  ホーム > プロフィール > 馬券ポートフォリオ > 2025年8月 |
|                                                        |
|  2025年8月の馬券成績                                   |
|  収支 / 的中率 / 回収率                                |
|                                                        |
|  +---------------------------------------------+      |
|  |  本文（当月の振り返り）                       |      |
|  +---------------------------------------------+      |
|                                                        |
|  券種別                                                |
|  +---------------------------------------------+      |
|  | 券種  件数 / 的中率 / 回収率 / 収支          |      |
|  +---------------------------------------------+      |
|                                                        |
|  購入履歴                                              |
|  +---------------------------------------------+      |
|  | 日付 / レース / 券種 / 結果 / 収支           |      |
|  +---------------------------------------------+      |
+--------------------------------------------------------+
|                        Footer                          |
+--------------------------------------------------------+
```
