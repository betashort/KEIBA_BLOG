# UI設計：共通レイアウト

上位文書: [画面設計書 §2](../screen_design.md#2-画面一覧) / [本ディレクトリ README](./README.md)

## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| 適用範囲 | 全画面 |
| 想定端末 | スマホ流入を基本（モバイルファースト） |
| 構成 | Header ＋ メインコンテンツ ＋ Footer ＋ SideNav（ドロワー） |
| 対応コンポーネント | `Header` / `SideNav` / `Footer` / `MetaTags` / `AdUnit`（所定画面） |

## 2. レイアウト構成

通常時（SideNav 閉じ）：

```
┌─────────────────────────────────────┐
│ Header（ロゴ ＋ ハンバーガー）       │
├─────────────────────────────────────┤
│                                     │
│  Main（画面固有コンテンツ）           │
│                                     │
├─────────────────────────────────────┤
│ Footer                              │
└─────────────────────────────────────┘
```

SideNav 開時：

```
┌──────────────┬──────────────────────┐
│              │ Header               │
│  SideNav     ├──────────────────────┤
│  （ナビ一覧） │                      │
│              │  Main（背面）         │
│              │  ※オーバーレイで暗転  │
│              ├──────────────────────┤
│              │ Footer               │
└──────────────┴──────────────────────┘
```

- Header 内に横並びのグローバルナビは置かない
- 画面遷移はハンバーガーから開く SideNav で行う

## 3. UI要素一覧

### 3.1 Header

| 要素 | 説明 | 遷移先 / 動作 |
| ---- | ---- | ------------- |
| サイトロゴ / サイト名 | ブランド表示 | `/` |
| ハンバーガーボタン | SideNav の開閉 | SideNav を開く / 閉じる |

### 3.2 SideNav（ドロワー）

| 要素 | 説明 | 遷移先 |
| ---- | ---- | ------ |
| 閉じる（× / ハンバーガー再タップ / オーバーレイ） | SideNav を閉じる | — |
| ナビ：ホーム | トップへ | `/` |
| ナビ：ブログ | ブログ一覧へ | `/blog` |
| ナビ：競馬研究 | 研究一覧へ | `/study` |
| ナビ：レース分析 | 分析一覧へ | `/analysis` |
| ナビ：レース予想 | 予想一覧へ | `/predict` |
| ナビ：プロフィール | プロフィールへ | `/profile` |

表示位置は画面左端からスライドインを基本とする（見た目・幅は未決）。

### 3.3 Footer

| 要素 | 説明 |
| ---- | ---- |
| コピーライト | サイト名・年号等 |
| （任意）補足リンク | プロフィール等。要検討 |

### 3.4 メタ・広告（共通方針）

| 要素 | 説明 |
| ---- | ---- |
| MetaTags | ページ単位で title / description / OGP を設定 |
| AdUnit | 記事詳細・一覧等の所定位置。読み込み前に領域確保（CLS 抑制） |

## 4. インタラクション

- SideNav の各項目から全画面へ到達可能（画面遷移図の note と一致）
- ハンバーガー押下で SideNav を開く。背面はオーバーレイでタップ不可とし、オーバーレイタップで閉じる
- ナビ項目選択後は SideNav を閉じ、遷移先を表示する
- 現在地のナビ項目はアクティブ表示とする（見た目は未決）
- 開いている間は背面スクロールをロックする

## 5. レスポンシブ

| 観点 | 方針 |
| ---- | ---- |
| 全ブレイクポイント | Header はロゴ＋ハンバーガーのみ。ナビは SideNav |
| デスクトップ | 横並びナビは採用しない（スマホ導線と揃える） |
