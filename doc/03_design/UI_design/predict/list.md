## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/race-predict` |
| 説明 | 開催日ごとのレース予想ページを、ブログ一覧と同じカードで新しい順に表示する |
| 対応コンポーネント | `PredictList` |
| og:type | `website` |

## 2. レイアウト

* ページ見出し「レース予想」を表示
* 開催日カードを新しい順で縦に一覧表示
  * サムネイル
  * タイトル（開催日。例: `2026/10/25`）
  * その日の競馬場
* 1ページあたり最大10件。11件目以降はページ下部のページネーションで切り替え
* カードタップでその日のレース予想ページ（`/race-predict/{YYYYMMDD}`）へ遷移
* 開催データが 0 件のときは「開催データはまだありません。」を表示

