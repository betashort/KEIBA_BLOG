## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/predict/{article_name}` |
| 説明 | Markdown から変換されたレース予想記事を表示 |
| 対応コンポーネント | `PredictPost` |
| og:type | `article` |

## 2. レイアウト

* パンくず（ホーム > レース予想 > 記事タイトル）
* タイトル（h1）・公開日・カテゴリ・タグを表示
* 本文（Markdown → HTML）を表示
* 所定位置に広告枠を確保
* 構成は [ブログ記事](../blog/article.md) と同様（パンくずの親のみ異なる）

**ワイヤーフレーム**
```
+--------------------------------------------------------+
|                        Header                          |
+--------------------------------------------------------+
|  ホーム > レース予想 > 記事タイトル                    |
|                                                        |
|  記事タイトル（h1）                                    |
|  公開日 / カテゴリ / タグ                              |
|  +---------------------------------------------+      |
|  | 広告枠                                       |      |
|  +---------------------------------------------+      |
|  |                                             |      |
|  |  本文（Markdown）                            |      |
|  |                                             |      |
|  +---------------------------------------------+      |
+--------------------------------------------------------+
|                        Footer                          |
+--------------------------------------------------------+
```
