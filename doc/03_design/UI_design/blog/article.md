## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/blog/{article_name}` |
| 説明 | Markdown から変換された記事を表示 |
| 対応コンポーネント | `BlogPost` |
| og:type | `article` |

## 2. レイアウト

* パンくず（ホーム > ブログ > 記事タイトル）
* タイトル（h1）・公開日・カテゴリ・タグを表示
* 本文（Markdown → HTML）を表示
* 所定位置に広告枠を確保

**ワイヤーフレーム**
```
+--------------------------------------------------------+
|                        Header                          |
+--------------------------------------------------------+
|  ホーム > ブログ > 記事タイトル                        |
|                                                        |
|  記事タイトル（h1）                                    |
|  公開日 / カテゴリ / タグ                              |
|  +---------------------------------------------+      |
|  | 広告枠                                       |      |
|  +---------------------------------------------+      |
|  |                                             |      |
|  |  本文（Markdown）                            |      |
|  |                                             |      |
|  +---------------------------------------------+      |
+--------------------------------------------------------+
|                        Footer                          |
+--------------------------------------------------------+
```
