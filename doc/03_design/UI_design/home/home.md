## 1. 基本情報

| 項目 | 内容 |
| ---- | ---- |
| URL | `/` |
| 説明 | サイトトップ。各セクションへの導線を表示 |
| 対応コンポーネント | `Home` |
| og:type | `website` |

## 2. レイアウト構成

```
Header
└─ Main
   ├─ サイトタイトル（ヒーロー級のブランド表示）
   ├─ 短いサイト説明（任意）
   └─ セクション導線
      ├─ ブログ → /blog
      ├─ 競馬研究 → /study
      ├─ レース分析 → /analysis
      ├─ レース予想 → /predict
      └─ プロフィール → /profile
Footer
```

## 3. UI要素一覧

| 要素 | 必須 | 説明 |
| ---- | ---- | ---- |
| サイトタイトル | ○ | ブランドの主表示 |
| サイト説明文 | △ | 一言のサポートコピー |
| ブログへのリンク | ○ | `/blog` |
| 競馬研究へのリンク | ○ | `/study` |
| レース分析へのリンク | ○ | `/analysis` |
| レース予想へのリンク | ○ | `/predict` |
| プロフィールへのリンク | ○ | `/profile` |

## 4. インタラクション

- 各セクション導線クリックで対応一覧（またはプロフィール）へ遷移
- SideNav からも同先へ遷移可能（重複導線は許容）

## 5. 表示状態

| 状態 | 表示 |
| ---- | ---- |
| 通常 | 上記導線を表示 |
| （記事件数 0） | 導線自体は維持。件数表示を入れる場合は「0件」等（要検討） |

## 6. レスポンシブ

| ブレークポイント方針 | 内容 |
| -------------------- | ---- |
| モバイル | 導線を縦積み |
| デスクトップ | 導線の並び・余白を最適化（グリッド等は未決） |
