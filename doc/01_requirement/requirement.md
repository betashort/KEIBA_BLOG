## 2. 背景・目的

### 2.1. 2.1 背景

- 競馬に関する学習内容・研究内容を体系的にまとめ、公開するブログサイトを構築したい

### 2.2 目的

- 競馬系の勉強記事・研究記事を発信する
- スマートフォン閲覧を前提としたブログサイトを提供する

<div style="page-break-after: always;"></div>

## 3. システム概要

### 3.1 システムの位置づけ

- 個人運営の競馬ブログサイト
- Webブラウザから閲覧する情報提供サイト

### 3.2 システム構成概要

- フロントエンド：React
- ビルドツール：Vite
- 言語：TypeScript
- UI：Tailwind CSS
- 記事管理：Markdown
- デプロイ先：Xserver

## 9. 非機能要件

### 9.1 性能要件

- 初回表示時のLCPは 2.5秒以内を目標とする
- 記事一覧・記事ページはモバイル環境での高速表示を重視する

---

### 9.2 可用性

- サイトは24時間閲覧可能であること
- 静的サイトとしてビルドし、Xserver上で安定稼働させる
- 障害時は再ビルド・再デプロイ可能な構成とする

---

### 9.3 セキュリティ

- ユーザー入力機能（コメント等）は提供しない
- dangerouslySetInnerHTML の入力元は管理者が作成した Markdown のみに限定する
- 外部スクリプトは信頼されたもののみ利用する

---

### 9.4 保守性・拡張性

- 記事はMarkdownファイルで管理し、容易に追加・修正できること
- カテゴリ・タグは拡張可能な設計とする
- SEO・OGP設定は記事単位で管理可能とする

---

### 9.5 SEO要件

- 各ページに以下のメタ情報を設定する  
  - title  
  - meta description  
- 記事ごとにユニークな title / description を設定する
- 見出し構造（h1〜h3）は論理的な階層構造とする
- h1は1ページにつき1つのみとする
- パンくずリストを設置する
- 記事URLは以下の形式とする  
  - /blog/{article_name}  
  - /study/{article_name}  
- モバイルファーストで設計する
- noindex / nofollow をページ単位で制御可能とする（将来拡張）

---

### 9.6 OGP・SNS連携要件

- 全ページでOGPタグを設定する  
  - og:title  
  - og:description  
  - og:type  
  - og:url  
  - og:image  
  - og:site_name  
- Twitter Card（summary_large_image）に対応する
- OGP画像は記事単位で設定可能とする
- 未設定時はデフォルト画像を使用する

---

### 9.7 広告・クローラ対応

- Google Adsを表示する
- 広告表示によるCLSを抑制する
- robots.txt を設置する
- sitemap.xml を生成する
